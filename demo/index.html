ShapeAudit · demonstração

Seu modelo novo tem a mesma acurácia.
Mas aprendeu a mesma coisa?

Toda vez que um modelo é retreinado, alguém decide se a versão nova sobe. A decisão costuma ser uma só: a acurácia caiu? Esta página acompanha uma semana de um modelo de cancelamento de clientes e mostra o que essa pergunta não cobre.

Dados públicos reais: 7.043 clientes de telecom  ·  biblioteca pip install shapeaudit

A métrica não distingue os três casos. Na sexta-feira, uma coluna passou a chegar sempre com o mesmo valor — e a acurácia quase não se mexeu. Na quarta, 23,5% dos clientes escolhidos para a campanha de retenção trocaram sem que nada no placar indicasse.

Como funciona

Três perguntas, feitas sobre os mesmos dados

  1. Alguma variável sumiu do modelo?

    Compara o peso de cada variável nas duas versões — e separa “a coluna sumiu do pipeline” de “o modelo decidiu não usar”.

  2. Os dados chegam como no treino?

    Compara o treino da versão nova com os dados que ela vai pontuar.

  3. O modelo passou a reagir de outro jeito?

    Compara a curva de efeito de cada variável entre as duas versões. Uma distância detecta a mudança; uma classificação em cinco formas a nomeia.

Cada laudo também declara o que não foi verificado. “Não checamos” e “está tudo bem” são frases diferentes.

8/10tipos de falha localizados: join perdido, escala, imputação, codificação, duplicação, vazamento, subgrupo…
  • Dois pontos cegos conhecidos: defasagem no tempo (deslocar uma coluna não muda a distribuição dela) e overfit (decorar o treino não muda quais variáveis importam).
  • Degradação parcial não bloqueia: com até 80% das linhas de uma variável corrompidas, o modelo perde 4 pontos e nada dispara.
  • Em bases pequenas é sensível: abaixo de ~400 linhas de avaliação, pede revisão em cerca de um terço dos retreinos saudáveis.
  • Fora de florestas é experimental (redes e modelos lineares).
  • Não diz qual das duas versões está certa — só que elas discordam.
  • Nenhum usuário externo validou ainda.

Em uma frase: confie no bloqueio para parar; não confie na ausência dele para seguir.
